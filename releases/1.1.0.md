# KDV Framework 1.1.0

Release scope approved by the project owner on 21 October 2026 after evaluation of the complete four-language preview.

## Changes

- Fifteen guides per language in English, Brazilian Portuguese, European Portuguese and Spanish: 60 guides in total.
- Five original editable Markdown templates per language, with clearer permitted-use/privacy fields and explicit indicator comparison direction.
- Worked examples for proactive municipal management across dispersed systems and professional-council inspection using authorised internal/external sources, with human validation before individual action.
- Deeper reference interpretation, implementation choices, AI/privacy decisions, preparation guidance and clearer reading/navigation groups.
- Familiar business vocabulary precedes Hive/Cell terminology without changing the anatomy or four-stage lifecycle.

## Compatibility and limits

This is a compatible addition to the v1.0.0 baseline. Existing guide slugs are preserved. English remains the default website language; `/pt/` remains European Portuguese and `/pt-br/` adds Brazilian Portuguese.

The framework remains independent of a specific platform. References are original KDV interpretations, not an official equivalence, certification or a claim that the full KDV stack is open source and delivered. Native Word/Excel materials are not distributed in this release. Technical records alone do not constitute a maturity assessment.

## Validation

The knowledge validator checks all 60 guides, 20 templates, four localized diagrams, matching locale inventories, links and the documented guardian policy. The coordinated website release records the exact knowledge commit it includes. Publication and repository protection status must be verified separately; this file alone is not proof of a GitHub release.
